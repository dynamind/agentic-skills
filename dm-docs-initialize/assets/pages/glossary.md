# Glossary

The {{SITE_NAME}} domain's terms: the words the users speak and the code declares, and the
real-world systems we integrate with. The domain terms are **deliberately ours**, copied
from no backend, so a change of system is an adapter change, not a domain change.

An entry is one or two sentences of domain meaning. No wire or code identifiers, no
mechanics; those belong in the feature docs. Domain terms stay in the language the
business speaks. The site links the first mention of a term on every other page to its
entry here and shows the first sentence as a tooltip, so write that sentence to stand
alone. Keep the `## Systems` heading: the linker uses it to tell a system from a domain
word.
