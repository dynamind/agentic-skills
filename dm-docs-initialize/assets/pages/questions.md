# Questions

Every question waiting on a human, in one place. One line each: a question nobody reads is a
question nobody answers. Prefix with who is asking; answers go on the `A:` line, dated.

Design questions we can settle ourselves stay in their feature doc, where the context is.

References point **outward from here**: a question names the code or doc it concerns. Code never
points back at this file; questions are ephemeral and the pointer would outlive them.
