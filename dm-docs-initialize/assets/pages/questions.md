# Questions

Every question waiting on a human, in one place. Keep each entry to one line, so a reader
can scan it and answer it. Prefix each entry with who is asking. Write the answer on the
`A:` line, dated.

Keep a design question that we can settle ourselves in its feature doc, where the context
is.

References point **outward from here**: a question names the code or doc it concerns. Code
never points back at this file. A question moves once it is answered, so a pointer from
code would soon point at the wrong place.
